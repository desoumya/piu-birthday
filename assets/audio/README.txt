Two audio files go in this folder. Both are optional — the site works
without them and never shows an error if they're missing.

  song.mp3
      Soft romantic instrumental. Loops quietly in the background from
      the moment she opens the envelope. The music note button in the
      top-right toggles it on/off. If this file is absent the button is
      simply dimmed and does nothing.

  birthday-song.mp3
      The happy-birthday song. Plays automatically the moment she blows
      out the candles, and stops after exactly 10 seconds. The background
      instrumental pauses while it plays and resumes afterwards.

Good free sources: Pixabay Music, YouTube Audio Library (filter by
"no copyright"). Keep filenames exactly as above.
